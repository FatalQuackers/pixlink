**New: Bluetooth.** Connect over Wi-Fi, Bluetooth or both (phone: Settings → Connect using). Same encryption as Wi-Fi. Screen sharing needs Wi-Fi.

**New: Updates page** on the PC with release notes, one-click install and an animated updating screen. The phone shows one too.

**PC**

- Splash screen, Home tab with pins, Settings as a tab, clear connection status
- Notifications expand fully, group by app, Open on phone, no pop-ups for old notifications

- Photo viewer, app icons and links in Messages, tray icon, logs, first-run setup

## Install
- **Pixel:** download `Pixlink-android.apk` on your phone and open it.
- **Windows (installer):** download `Pixlink-Setup-x64.exe` and run it. No admin needed.
- **Windows (portable):** download `Pixlink-windows-x64-portable.zip`, extract it anywhere and run `Pixlink.exe`.

Already have Pixlink? Both apps update themselves.
