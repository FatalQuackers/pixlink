## Install
- **Pixel:** download `Pixlink-android.apk` on your phone and open it.
- **iPhone:** install `Pixlink-iOS.ipa` with AltStore, SideStore or Sideloadly.
- **Windows (installer):** download `Pixlink-Setup-x64.exe` and run it. No admin needed.
- **Windows (portable):** download `Pixlink-windows-x64-portable.zip`, extract it anywhere and run `Pixlink.exe`.

Already have Pixlink? It updates itself.
